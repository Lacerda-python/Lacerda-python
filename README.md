## 📊 Projetos em Destaque

### L&P Finanças 💰
Aplicação web para gestão financeira desenvolvida do zero. Um dos meus principais projetos práticos.

**Tecnologias utilizadas:**
- **Backend:** Python, Flask, REST API
- **Frontend:** HTML, CSS, JavaScript
- **Banco de Dados:** Supabase (PostgreSQL)
- **Arquitetura:** Aproximadamente 20 rotas REST distribuídas em 5 tabelas

**Funcionalidades:**
- CRUD completo de transações financeiras
- Autenticação e gerenciamento de usuários
- Relatórios e dashboards
- API RESTful com boas práticas
